Password Strength Checker

POST /api/password/strength — evaluates length, character diversity and estimated resistance to guessing.

Secure Password Generator

POST /api/password/generate — generates a cryptographically secure random password.

Memorable Passphrase Generator

POST /api/passphrase/generate — a Diceware-style passphrase of randomly selected words.

Multiple random words produce a passphrase that is both long (strong) and easy to remember.

Two-Factor Authentication (TOTP)

POST /api/2fa/setup and POST /api/2fa/verify — register a user, scan the QR code, then verify a six-digit code.

1 Enter a username and request a QR code.
2 Scan it with Google Authenticator or Microsoft Authenticator.
3 Enter the six-digit code shown in the app to verify.

Breached Password Checker

POST /api/password/breach-check — checks the password against known data breaches via Have I Been Pwned.

k-anonymity: the backend sends only the first five characters of the password's SHA-1 hash to HIBP. Your full password is never transmitted to any third party — only an anonymised hash prefix is used to retrieve candidate matches, which are then checked locally on the backend.

About this Project

Password Protection and Management Microservice is a university project for a Computer Science degree specialising in Information Security.

The system consists of five independent microservices — password strength analysis, secure password generation, memorable passphrase generation (Diceware), time-based one-time password (TOTP) two-factor authentication, and breached-password detection via the Have I Been Pwned k-anonymity API — orchestrated by a FastAPI backend and consumed through this web dashboard.

The frontend is built with plain HTML5, CSS3 and vanilla JavaScript. It communicates with the backend exclusively over REST (HTTP/JSON) using the Fetch API. Passwords and TOTP codes are never stored in the browser, never written to local storage, and are cleared from memory after each request.
